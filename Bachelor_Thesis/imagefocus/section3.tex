\section{Methodology}
\subsection{Overall Framework}
\par This study builds a complete experimental pipeline for patch-based image
focus detection \cite{Hou_2016_CVPR}, covering the full process from data
preprocessing to result evaluation. From the perspective of practical
execution, the method mainly contains the following three connected stages:
\begin{itemize}
    \item \textbf{Preprocessing stage}: image normalization, patch division,
    automatic labeling, manual inspection, and construction of training input;
    \item \textbf{Model training stage}: training of classical machine learning
    models and a lightweight convolutional neural network under unified data
    organization;
    \item \textbf{Evaluation stage}: metric calculation, result comparison, and
    prediction visualization output.
\end{itemize}
\par At the same time, for clearer methodological description, this section
also lists the experimental design as a separate part to explain the overall
arrangement of pre-experiments, main experiments, and supplementary analyses.
This pipeline connects classical machine learning methods and the lightweight
convolutional neural network through a unified data organization format, so as
to ensure fair comparison under the same task definition.

\par In terms of task definition, this thesis considers both three-class and
binary patch focus discrimination settings. For the three-class task, each
input grayscale patch is mapped to one of three classes, namely blur, sharp,
or intermediate, and the classification function can be written as
\begin{equation}
    f_3: \mathbb{R}^{h\times w} \to \left\{ 0,1,2 \right\}
    \label{eq:3-Classification}
\end{equation}
\par where $0$ denotes blur, $1$ denotes sharp, and $2$ denotes intermediate.
For the binary setting, only the blur and sharp classes are retained, and the
mapping is written as
\begin{equation}
    f_2: \mathbb{R}^{h\times w} \to \left\{ 0,1 \right\}
    \label{eq:2-Classification}
\end{equation}
\par where $0$ denotes blur and $1$ denotes sharp. The two task forms share the
same preprocessing, feature extraction, and scoring process, and differ only
in the final label mapping rule. It should be noted that for patches with too
weak texture to judge focus state reliably, the automatic labeling stage
additionally assigns an ignore label $y=-1$. Such samples are uniformly
filtered out before training and evaluation, and therefore are not included in
the valid class set of the binary or three-class task.

\par In the method pipeline, the original image is first converted to grayscale
and normalized in size to ensure consistency in the subsequent grid division.
The normalized image is then divided into fixed-size non-overlapping patches,
and focus-related local features are computed for each patch. Based on these
features, patch labels are automatically generated by fusing multiple
sharpness indicators, and training and validation samples are then
constructed. Finally, classical machine learning models and a lightweight CNN
are trained separately, and their performance is compared under unified
evaluation metrics. The whole framework considers repeatability,
interpretability, and experimental controllability, which is consistent with
the goal of this thesis to conduct comparative research under limited-data
conditions.

\par Figure~\ref{fig:overall-framework} shows the overall execution pipeline of
the proposed method. The heatmaps and focus maps generated after automatic
labeling are used for manual inspection. If the inspection result is not
satisfactory, the process returns to the threshold setting and label
generation stage for adjustment until the labeling result is basically
consistent with human visual judgment. The specific label mapping rules for
binary classification, three-class classification, and textureless patches
will be described in the following subsections.

\subsection{Preprocessing}
\subsubsection{Size Normalization and Grayscale Conversion}
\par To reduce the heterogeneity of input data and ensure consistency of patch
representation, this thesis first preprocesses the original images, as shown
in Fig.~\ref{fig:preprocessing}. Preprocessing starts with size alignment. To
ensure that an image can be evenly divided by a fixed patch size, the image
size is adjusted to be compatible with the preset patch size. This step avoids
the problem of inconsistent boundary patch size and therefore guarantees a
unified format for subsequent feature extraction and model input.
\begin{equation}
    \tilde{h}=\left\lceil \frac{h}{p} \right\rceil p,\qquad
    \tilde{w}=\left\lceil \frac{w}{p} \right\rceil p
    \label{eq:resize-shape}
\end{equation}
\begin{equation}
    I_r=\operatorname{Resize}(I,\tilde{w},\tilde{h})
    \label{eq:resize-op}
\end{equation}
\par where $I$ denotes the original input image, $p$ denotes the preset patch
size, $\tilde{h}$ and $\tilde{w}$ denote the adjusted image height and width,
respectively, and $I_r$ denotes the size-normalized image. The above rule
means that if the original size in one direction is divisible by $p$, it
remains unchanged; otherwise, one block is added on the basis of the
corresponding block number and then multiplied back by $p$, so that the size
is extended to the next divisible value.

\par For example, when the original resolution is $1680\times1120$ and the
patch size is $p=32$, in the height direction we have
\begin{equation}
    1120 \div 32 = 35
\end{equation}
\par Therefore, the height is already divisible and remains
$\tilde{h}=35\times32=1120$. In the width direction we have
\begin{equation}
    1680 \div 32 = 52.5
\end{equation}
\par which is not divisible. The block number is therefore extended from $52$
to $53$, and we obtain
\begin{equation}
    \tilde{w}=53\times32=1696
\end{equation}
\par Hence, the image is finally adjusted to $1696\times1120$.

\par For the choice of patch size, this thesis uses $p=32$ by default. The
reason is that this scale provides a relatively good balance between local
detail preservation and contextual completeness. If the patch is too small,
for example $8$ or $16$, it can provide finer spatial resolution, but the
texture and edge information contained in a single patch become too limited,
which may make the discrimination between clear and blurred states unstable.
At the same time, the number of patches increases significantly, which also
raises the computational cost in labeling, training, and validation. In
contrast, if the patch is too large, for example $64$ or above, local
statistics become more stable, but a single patch may contain both clear and
blurred regions at the same time, which weakens the purity of patch-level
labels and is not favorable for describing focus boundaries precisely.

\par By comparison, a $32\times 32$ patch can preserve sufficient local
structural information while keeping each sample in a relatively low-
dimensional range, and it is also more suitable for the unified input design
of subsequent classical machine learning models and lightweight CNNs.
Therefore, this thesis takes $p=32$ as the default setting and performs
automatic labeling, model training, and result comparison on this basis.

\par After size alignment, the image is further converted into grayscale
\cite{1284395} to reduce the additional dimensional interference brought by
color information, so that the model can focus more on luminance, edge, and
texture variations related to sharpness. The grayscale conversion is expressed
as
\begin{equation}
    I_g(x,y)=0.299R(x,y)+0.587G(x,y)+0.114B(x,y)
    \label{eq:grayscale}
\end{equation}
\par where $I_g$ denotes the grayscale image, and $R(x,y)$, $G(x,y)$, and
$B(x,y)$ denote the values of pixel $(x,y)$ in the three color channels,
respectively.

\subsubsection{Patch Extraction Strategy}
\par After grayscale conversion and size alignment, the image is divided into
fixed-size non-overlapping patches to form a regular grid representation
\cite{Hou_2016_CVPR}. The row and column positions of each patch in the grid
are encoded in its filename, which is later used for label file construction
and visualization of projecting predictions back onto the original image. This
non-overlapping partition strategy is adopted mainly to preserve local spatial
information while controlling sample quantity and computational complexity, so
that different models can be trained and evaluated on the same basic unit. It
should also be noted that no additional conventional image augmentation, such
as rotation, flipping, or color perturbation, is used in the preprocessing and
automatic labeling stages. This is because the images used for testing and
validation already cover multiple scene conditions, including indoor, outdoor,
strong illumination, and weak illumination. The data themselves therefore
already have some environmental diversity, and this thesis prioritizes
examining the model's ability to distinguish real focus differences under the
original distribution.
\begin{equation}
    n_r=\frac{\tilde{h}}{p},\qquad n_c=\frac{\tilde{w}}{p}
    \label{eq:grid-size}
\end{equation}
\begin{equation}
    P_{i,j}=I_g[ip:(i+1)p,\; jp:(j+1)p],\quad
    0\le i<n_r,\; 0\le j<n_c
    \label{eq:patch-split}
\end{equation}
\par In this way, one image can be represented as the regular patch set
$\{P_{i,j}\}$, where $(i,j)$ corresponds to the position index of the patch in
the original image grid.

\subsubsection{Feature Extraction and Labeling}
\subsubsection{Focus Features and Their Physical Meaning}
\par After patch division, this thesis extracts sharpness features related to
focus state from each local image block. Specifically, three types of features
are used, namely Laplacian, Sobel, and fast Fourier transform (FFT), to
describe the edge response, gradient strength, and frequency-domain high-
frequency information of each patch \cite{5739529,1284395}. These features
reflect local sharpness from different perspectives. Laplacian emphasizes
details and higher-order variation, and its score is defined as
\begin{equation}
    s_{\mathrm{lap}}(P)=\operatorname{Var}\!\left(\nabla^2 P\right)
    \label{eq:lap-score}
\end{equation}
\par Sobel describes the distribution of edge gradients. The horizontal and
vertical gradients are first computed as
\begin{equation}
    G_x=S_x * P,\qquad G_y=S_y * P
    \label{eq:sobel-grad}
\end{equation}
\par and then the average gradient magnitude is used as the sharpness
indicator:
\begin{equation}
    s_{\mathrm{sob}}(P)=\frac{1}{|P|}\sum_{(x,y)\in P}\sqrt{G_x(x,y)^2+G_y(x,y)^2}
    \label{eq:sobel-score}
\end{equation}
\par FFT measures the preservation of high-frequency components. To reduce the
interference of brightness scale differences on frequency-domain statistics,
the patch is first normalized and the spectrum is centered:
\begin{equation}
    \hat{P}=\mathcal{F}\!\left(\frac{P-\mu_P}{\sigma_P+\varepsilon}\right),\qquad
    M=\log\!\left(1+\left|\operatorname{fftshift}(\hat{P})\right|\right)
    \label{eq:fft-prepare}
\end{equation}
\par The high-frequency energy ratio is then measured over the high-frequency
region $\Omega_h$, defined as
\begin{equation}
    s_{\mathrm{fft}}(P)=
    \frac{\sum_{(u,v)\in \Omega_h} M(u,v)}
    {\sum_{(u,v)} M(u,v)+\varepsilon}
    \label{eq:fft-score}
\end{equation}
\begin{equation}
    \Omega_h=\left\{(u,v)\mid (u-c_y)^2+(v-c_x)^2\ge r^2\right\},\qquad
    r=0.3\min(c_y,c_x)
    \label{eq:fft-mask}
\end{equation}
\par where $s_{\mathrm{lap}}$ denotes the variance of Laplacian,
$s_{\mathrm{sob}}$ denotes the average gradient magnitude, and
$s_{\mathrm{fft}}$ denotes the frequency-domain high-frequency energy ratio.
$\mu_P$ and $\sigma_P$ denote the mean and standard deviation of patch $P$,
respectively, and $\Omega_h$ denotes the region in the spectrum used for
high-frequency energy calculation. By fusing these three types of features, a
more stable local sharpness score can be obtained.

\subsubsection{Automatic Label Generation}
\par Different from manual patch-by-patch annotation, this thesis adopts an
automatic labeling strategy to construct patch-level supervisory signals. The
specific procedure is to first calculate the fused sharpness score of each
patch according to the above features, and then generate the corresponding
label under the current task setting according to preset thresholds. This
thesis first defines a sharp threshold $T_s$ and a blur threshold $T_b$, with
$T_b\le T_s$. When $T_b=T_s$, the system degenerates to the binary
classification setting, where patches above the threshold are labeled as sharp
and those below the threshold are labeled as blur. When $T_b<T_s$, the system
uses the three-class setting, where patches lower than $T_b$ are labeled as
blur, those higher than $T_s$ are labeled as sharp, and those between the two
are labeled as intermediate. In addition, for patches with too weak texture to
judge focus state reliably, this thesis marks them as textureless samples
($y=-1$) and filters them out in training and evaluation to reduce the
interference of noisy labels on model learning. For this purpose, some raw
features are first normalized by the following compression function:
\begin{equation}
    \phi(x;a)=\frac{x}{x+a}
    \label{eq:score-squash}
\end{equation}
\par On this basis, the fused sharpness score $S(P)$ is defined as
\begin{equation}
    S(P)=
    \begin{cases}
        0.7\,\phi(s_{\mathrm{sob}};a_s)+0.3\,\phi(s_{\mathrm{lap}};a_l), & p\le 32,     \\
        0.5\,\phi(s_{\mathrm{lap}};a_l)+0.5\,s_{\mathrm{fft}},           & 32<p\le 128, \\
        0.7\,s_{\mathrm{fft}}+0.3\,\phi(s_{\mathrm{lap}};a_l),           & p>128,
    \end{cases}
    \label{eq:fused-score}
\end{equation}
\par For patches with too weak texture to judge focus state stably, this thesis
further uses the following textureless decision rule:
\begin{equation}
    \operatorname{textureless}(P)=
    \left[\operatorname{Std}(P)<\tau_{\mathrm{std}}\right]
    \land
    \left[s_{\mathrm{sob}}(P)<\tau_{\mathrm{sob}}\right]
    \label{eq:textureless}
\end{equation}
\par The textureless samples here do not mean that the region is physically
``unable to focus''. Instead, they refer to patches in a single two-
dimensional image that simultaneously lack obvious grayscale variation, edge
structure, and high-frequency texture information, so that their focus state
cannot be judged stably by local sharpness features alone. In other words,
$y=-1$ does not correspond to a new focus category, but to an unreliable-to-
judge marker. Such regions usually appear visually as large nearly uniform
color blocks, weak-texture backgrounds, or flat regions with very small
brightness variation. Since a single image does not directly provide the true
depth of field or scene distance information, for such patches without
observable structural cues, it is difficult to distinguish whether they are
sharp or blurred only from local appearance, even if optical focusing has
actually been completed in the imaging process. Therefore, if they are forced
into the blur, sharp, or intermediate class during automatic labeling, strong
label noise is likely to be introduced, which weakens the model's ability to
learn effective focus boundaries. Based on this consideration, this thesis
uniformly assigns them the ignore label $y=-1$ and filters them out before
subsequent training and evaluation.

\par Under the three-class setting, the output of the automatic labeling
function can be written as
\begin{equation}
    y(P)=
    \begin{cases}
        -1, & \operatorname{textureless}(P)=1, \\
        1,  & S(P)\ge T_s,                     \\
        0,  & S(P)<T_b,                        \\
        2,  & T_b\le S(P)<T_s,
    \end{cases}
    \qquad (T_b<T_s)
    \label{eq:tri-label}
\end{equation}
\par Under the binary setting, the automatic labeling function is further
simplified as
\begin{equation}
    y(P)=
    \begin{cases}
        -1, & \operatorname{textureless}(P)=1, \\
        1,  & S(P)\ge T,                       \\
        0,  & S(P)<T,
    \end{cases}
    \qquad (T_b=T_s=T)
    \label{eq:binary-label}
\end{equation}
\par Through this process, discrete supervisory labels can be automatically
generated from continuous sharpness scores. It should be emphasized that the
strategy used here is rule-based automatic labeling \cite{5739529,1284395},
rather than pseudo-labeling recovered from the prediction results of an
existing model \cite{lee2013pseudo}. The thresholds themselves are not set only
once. Instead, they are determined iteratively through the process of
``setting candidate $T_b,T_s$ -- generating heatmaps and label maps --
comparing them with the original image -- adjusting the thresholds again''.
In the experiments of this thesis, the default values are $T_s=0.75$ and
$T_b=0.40$. When binary classification is used, $T_b=T_s=T$ so that the system
degenerates to a single-threshold division. These thresholds are finally
determined through repeated manual observation and sample checking, with the
goal of establishing the closest possible correspondence between automatic
rules and human visual judgment. Although this automatic labeling may still
retain some systematic bias, both the training set and validation set are
generated based on the same rules. Therefore, this bias mainly affects the
absolute values of the metrics, while its interference with the relative
differences between models is expected to be limited. Based on this
consideration, this thesis considers that this strategy achieves a reasonable
balance among labeling cost, repeatability, and fairness of comparison.

\subsubsection{Patch Representation for Model Training}
\par In the setting of this thesis, the anchor parameters for normalizing
Laplacian and Sobel features are set as $a_l=300$ and $a_s=12$, respectively.
The filtering thresholds for textureless samples are set as
$\tau_{\mathrm{std}}=3$ and $\tau_{\mathrm{sob}}=2$. With these rules,
continuous sharpness scores can be stably mapped into binary or three-class
labels. It should be noted that the above Laplacian, Sobel, and FFT scores are
mainly used for automatic labeling rather than as the final input features of
classical classifiers. In the supervised training stage, model input is
constructed from the grayscale patches generated in preprocessing, so as to
ensure that classical machine learning methods and CNNs are compared on the
same basic data unit. Before supervised training, all textureless samples with
label $y=-1$ are filtered out. Therefore, the actual valid class set learned
by the model is $\{0,1,2\}$ under the three-class setting and $\{0,1\}$ under
the binary setting. For a grayscale patch $P$ of size $p\times p$, its input
vector for classical models is represented as
\begin{equation}
    \tilde{\mathbf{z}}(P)=\frac{1}{255}\,\operatorname{vec}(P)\in\mathbb{R}^{p^2}
    \label{eq:ml-input-vector}
\end{equation}
\par When the input dimension is high, PCA is further applied to the training
sample matrix \cite{perry2025inference,zheng2021application}. If the original
sample matrix is denoted by $X\in\mathbb{R}^{N\times p^2}$, the reduced
representation can be written as
\begin{equation}
    X_{\mathrm{pca}}=(X-\mathbf{1}\boldsymbol{\mu}^\top)W,\qquad
    W\in\mathbb{R}^{p^2\times k}
    \label{eq:ml-pca}
\end{equation}
\par where $N$ denotes the number of samples, $\boldsymbol{\mu}$ denotes the
feature mean vector, $W$ denotes the principal component matrix, and $k$
denotes the number of principal components after reduction. Its specific value
will be further analyzed according to performance in later experiments.

\subsubsection{PCA-Based Visual Inspection of Class Separability}
\par It should be especially emphasized that the PCA visualization here is not
a formal dimensionality reduction step that must be executed before training,
and it does not change the main workflow of subsequent model training,
validation, or result comparison. It belongs to the manual diagnosis and
auxiliary inspection stage. After preprocessing and automatic labeling are
completed, the researcher additionally performs one PCA projection on the patch
samples to observe whether the current label system shows preliminary
separability in low-dimensional space, thus helping judge whether the
automatic labeling result is generally reasonable. This step belongs to the
same type of manual inspection procedure as the previously mentioned heatmap
visualization. Its purpose is not to perform classification directly, but to
observe from a low-dimensional projection perspective whether different class
samples show relatively clear distribution trends and whether class boundaries
are generally distinguishable.

\par Specifically, the flattened grayscale patch vectors are first constructed
according to Eq.~\eqref{eq:ml-input-vector}, and then projected into the
two-dimensional and three-dimensional principal component spaces by PCA. For
the binary task, the main observation is whether the sharp and blur samples
show relatively obvious clustering and separation. For the three-class task, it
is further examined whether the intermediate class is distributed between the
other two classes and whether this is consistent with the automatic labeling
logic of this thesis. It should be noted that such 2D and 3D scatter plots are
essentially only low-dimensional projections of high-dimensional feature
distributions. They cannot be used alone as a basis for classification and
cannot replace subsequent supervised model training. However, if the class
clusters in the plots already show relatively clear structure, they can serve
as auxiliary evidence that the current preprocessing, patch representation, and
automatic labeling rules are reasonable.

\par Figures~\ref{fig:pca-2d-visualization} and
\ref{fig:pca-3d-visualization} show the PCA visualization results of the same
sample under the binary and three-class settings. It can be seen from the
figures that although there is still some overlap between different classes,
relatively clear clustering trends can already be observed overall. In
particular, the distribution difference between the sharp and blur samples in
principal component space is relatively obvious, and the intermediate class in
the three-class setting is mainly located in the transition region between the
other two. This indicates that at the same stage when preprocessing is
completed and heatmaps are generated, patch-level features already have some
separability, and the class boundaries are generally observable and
interpretable, which provides a good basis for subsequent classifier training.

\subsubsection{Visualization and Manual Verification}
\par It should be noted that the visual results in this thesis are divided into
two stages. The first stage is score-based visualization. A continuous-value
heatmap is first generated from the fused score of each patch, and then mapped
to binary or three-class focus maps according to candidate threshold rules.
This stage does not yet involve model training and is mainly used to show the
local sharpness distribution and the effect of automatic labeling. More
importantly, these heatmaps and classification maps are not generated only once
and then fixed. They are repeatedly used as the basis for manual verification
and threshold calibration. The researcher compares the original image, the
continuous-score heatmap, and the binary and three-class label maps, checks
whether local sharp regions, blurred regions, and threshold-based partition
results are basically consistent, and repeatedly adjusts the threshold
parameters until the visual result reaches relatively stable consistency with
human visual judgment. The second stage takes place after supervised training
is completed. The patch-level prediction results of the model are projected
back to the original image to generate prediction maps, which are used to
compare the actual discrimination performance of different classifiers.

\par Figure~\ref{fig:comparison} shows the result of the first stage, namely
the visual output of the same sample in the threshold calibration process of
automatic labeling. The figure is organized in the order of ``top left:
original image, top right: continuous-score heatmap, bottom left: binary
result, bottom right: three-class result''. The continuous-score heatmap is
not generated directly from discrete labels. Instead, the fused sharpness score
$S(P)$ of each patch is first filled back into its corresponding position
according to the grid coordinate $(i,j)$ to form a score map, where the
definition of $S(P)$ is given in Eq.~\eqref{eq:fused-score}. This grid is then
expanded back to the original image size by nearest-neighbor interpolation and
overlaid on the original image with pseudo-color mapping. Therefore, the
heatmap reflects the spatial distribution of continuous focus scores rather
than the class result after threshold partition.

\par In contrast, the binary and three-class focus maps are generated from
discrete label maps. Specifically, the grid coordinates are parsed from the
patch filenames, the label $y(P)\in\{-1,0,1,2\}$ is placed into the
corresponding patch grid, and then restored to the original image size by
nearest-neighbor interpolation and finally overlaid on the original image in a
semi-transparent form. Since the label map rather than the continuous score
map is used here, this visualization essentially corresponds to the automatic
labeling result after threshold-rule mapping, rather than the prediction
output after model training.

\par To enhance the distinguishability among different classes, the label
overlay map is displayed with semi-transparent masks. The sharp region is
highlighted in red and its boundary is additionally outlined. Under the
three-class setting, the intermediate class is shown in blue, the textureless
class is shown in green, and the blur class $y=0$ is not given any additional
color mask and therefore preserves the original image appearance. For the
binary result map, since there is no intermediate class $y=2$, the figure
mainly shows the red overlay of sharp regions, the green overlay of
textureless regions, and the blurred regions remaining as the original image.
This display makes the difference between the continuous-score heatmap and the
discrete label visualization clearer.

\subsection{Model Training}
\subsubsection{Class Imbalance Consideration}
\par In this task, label $1$ corresponds to the sharp-class patch, and this
class usually accounts for a relatively small proportion in the actual data.
This phenomenon is related to the focus distribution of the image itself. For
a single image, the regions truly located within the best focus range usually
occupy only part of the scene, while many background regions, defocused
regions, and weak-texture regions are more easily labeled as blur,
intermediate, or textureless samples. Especially after patch-level division,
sharp regions often cover only local object edges or a small number of key
structures. Therefore, from the perspective of sample quantity, the sharp
class is more likely to become the minority class.

\par For classical machine learning models, class imbalance directly affects the
optimization direction of the training objective. Without additional handling,
the classifier tends to fit the majority classes first, and as a result, the
recall of the minority sharp patches may remain low even when the overall
accuracy appears high. For the focus detection task of this study, this bias
makes the model more likely to misclassify truly sharp regions as blur or
intermediate, and therefore weakens its ability to recognize clear regions.
For this reason, this thesis introduces class weighting in the subsequent
classical machine learning models to alleviate the training bias caused by
uneven sample distribution.

\subsubsection{Classical Machine Learning Models}
\par In the classical machine learning part, this thesis selects three
representative classification models, namely decision tree, random forest, and
support vector machine. Their common characteristic is that they take the
pre-extracted patch representation as input and then establish the mapping
between focus state and feature vector through supervised learning. The reason
for selecting these three models is that they represent different modeling
ideas, including single-model rule partition, ensemble learning, and margin-
maximization classification, and can therefore reflect the performance
characteristics of traditional methods in this task more comprehensively.

\subsubsection{Shared Training Pipeline}
\par Decision trees \cite{breiman2017classification} construct classification
rules by recursively partitioning the feature space. They train quickly and
have strong interpretability, but are prone to overfitting under complex data
distribution. Random forests \cite{breiman2001random} reduce the instability of
a single model by ensembling multiple decision trees, and usually have better
robustness and generalization. Support vector machines
\cite{cortes1995support} are suitable for discrimination on small- and medium-
scale samples and can construct relatively strong class boundaries in high-
dimensional feature space. In the experiments of this thesis, these models are
all trained under the same training data and the same label settings, so that
their results are comparable with those of the subsequent CNN method. Through
this design, the performance boundary of traditional feature-driven methods
under small-sample conditions can be observed more clearly.

\par In the training setting, all three classical models use the pixel vector of
grayscale patches as input. Specifically, each patch is first uniformly
represented as a grayscale image of size $p\times p$, then normalized to the
interval $[0,1]$ and flattened into a one-dimensional feature vector, namely
the representation shown in Eq.~\eqref{eq:ml-input-vector}. In the training
stage, the training samples and labels are first collected, and the
textureless samples with label $y=-1$ are removed. When necessary, training
samples can also be randomly sampled according to a preset ratio to support
comparative experiments under different sample sizes. All patch vectors are
then assembled into a training matrix, which can be further sent into
principal component analysis (PCA) for dimensionality reduction according to
the experimental setting. When the reduced dimension is set as invalid or is
not lower than the original dimension, the original pixel vectors are retained
for direct training.

\subsubsection{Decision Tree and Random Forest}
\par Decision tree and random forest both operate directly on the original or
PCA-compressed patch representation. In the experimental setting of this
thesis, the decision tree uses constrained tree depth, relatively large minimum
split sample number, and relatively large minimum leaf sample number, together
with balanced class weights, to suppress overfitting. The random forest uses
$100$ base learners, a maximum depth of $16$, and a balanced subsampling
weighting strategy, with a fixed random seed to ensure repeatability.
Specifically, the decision tree suppresses overfitting through larger leaf-node
and split thresholds, while the random forest improves robustness and
generalization through the ensemble of multiple weakly correlated trees.

\subsubsection{Nystr\"{o}m-Based SVM}
\par Support vector machines can use either a purely linear form or a kernel
function to characterize nonlinear decision boundaries. For the patch focus
detection task in this thesis, both choices have their own advantages and
limitations. Pure linear SVM trains faster, uses fewer parameters, and is
relatively stable in high-dimensional input spaces. When the sample size
increases, its time and memory cost are also easier to control, and therefore
it has good engineering feasibility. However, the decision boundary of a pure
linear model is still limited by the original feature space or the linear
subspace after PCA. When sharp and blurred patches show a more complex
nonlinear distribution, its expressive ability may be insufficient. In
contrast, a pure kernel SVM can construct more flexible classification
boundaries in implicit high-dimensional space through the kernel trick, and is
therefore more suitable for handling nonlinear differences among local texture
and edge patterns. The cost, however, is that the training process usually
depends on kernel-matrix computation, which brings higher time and memory
burden when the sample number is large, and is also not favorable for the
efficient execution of later comparative experiments involving multiple
parameter groups and sample sizes.

\par Based on these considerations, this thesis does not treat pure kernel SVM
and pure linear SVM as an either-or choice. Instead, Nystr\"{o}m kernel
approximation is adopted as a compromise between the two. Its basic procedure
is as follows: the PCA-transformed input features are first standardized, then
the RBF kernel is mapped into a finite-dimensional approximate feature space by
the Nystr\"{o}m method, and finally the classification is completed by a linear
support vector classifier. The purpose is to retain as much nonlinear
expressive ability of kernel methods as possible while transforming the
training process into a linear classification problem in an approximately
explicit feature space, thereby balancing representation ability and
computational efficiency. If $\varphi(\cdot)$ denotes the approximate kernel
mapping, the implemented SVM form can be written as
\begin{equation}
    f(\mathbf{r})=\mathbf{w}^\top \varphi(\mathbf{r})+b
    \label{eq:svm-nystroem}
\end{equation}
\par where $\mathbf{r}$ denotes the patch representation after PCA. In the
experimental setting, the model complexity can be adjusted by hyperparameters
such as kernel form, approximation dimension, kernel width parameter,
regularization coefficient, and maximum iteration number. Therefore, the final
choice of SVM based on Nystr\"{o}m kernel approximation is not made to prove
that it is absolutely better than the other two SVM forms under all settings,
but because it better matches the balance pursued in this research among
nonlinear modeling ability, training cost, and experimental operability.

\subsubsection{Imbalance Handling in ML Models}
\par To alleviate the effect of class imbalance, class weighting is enabled in
all three classical models so that minority-class samples receive higher
importance during training. The decision tree and SVM use global balanced class
weights, while the random forest introduces balanced weighting at the
subsampling level. After training, both the classifier itself and the
corresponding PCA transformer are retained so that consistent feature
transformation and prediction can be performed on new patches in the validation
stage.

\subsubsection{Lightweight CNN Model}
\par To compare with classical machine learning methods, this thesis also builds
a lightweight convolutional neural network (CNN) for patch classification
\cite{lecun2002gradient,krizhevsky2012imagenet}. Different from models based on
hand-crafted features, the CNN directly takes raw patch pixels as input and
automatically learns local patterns related to sharpness discrimination through
convolution layers. Since the research focus of this thesis is performance
comparison under limited-data conditions rather than pursuing the extreme
accuracy of deep networks, the adopted CNN structure is controlled in both
parameter scale and network depth to reduce the risk of overfitting and improve
training feasibility.

\subsubsection{Design Rationale and Imbalance Strategy}
\par This lightweight CNN consists of several convolutional modules and
classification layers. The network depth can be adapted according to patch size
so that relatively stable feature extraction ability can be maintained under
different input scales. During training, the model uses a loss function
suitable for classification tasks and handles sample imbalance through class
weighting or resampling strategies. It should be noted that although resampling
and loss weighting both serve minority-class learning, their mechanisms are
different. The former increases the occurrence frequency of minority classes by
adjusting the sampling distribution of mini-batches, while the latter directly
adjusts the error weights of different classes in the loss function. This
thesis keeps both strategies in the training framework so that later
experiments can compare the effects of different imbalance-handling schemes.
Considering that CNNs can already achieve good discriminative accuracy in image
classification tasks, this thesis does not introduce large-scale additional
augmentation, but only adds lightweight noise perturbation within a controlled
range to improve the model's general applicability under different acquisition
conditions. This is also consistent with the common practice of improving the
robustness of vision models. The purpose of choosing a lightweight CNN is not
to compete with large deep models, but to examine whether, when network
complexity is controlled, it can show stronger automatic feature learning
ability than traditional methods in limited-data scenarios.

\subsubsection{Input Representation and Adaptive Architecture}
\par In the input representation, the grayscale patch is normalized to the
interval $[0,1]$ and organized as a single-channel tensor:
\begin{equation}
    X(P)=\frac{1}{255}P\in\mathbb{R}^{1\times p\times p}
    \label{eq:cnn-input-method}
\end{equation}
\par The network structure is adaptively adjusted according to patch size. For
smaller inputs, the network uses a shallower convolution structure. As the
patch size increases, the number of convolution layers is also increased, so as
to enlarge the effective receptive field while controlling parameter scale.
Specifically, when $p\le 16$, one convolution layer plus pooling is used. When
$16<p\le 64$, two convolution modules are used. When $p>64$, three
convolution modules are used. The reason for this adaptive design is that
different patch sizes correspond to different spatial scales and information
density. For smaller patches, the input region itself contains limited local
structure. If too many convolution layers are used, the feature maps shrink too
quickly after repeated pooling, which is not favorable for preserving useful
details. For larger patches, however, if the network remains too shallow, the
receptive field becomes insufficient and it is difficult to integrate texture
and edge information over a larger range. Therefore, instead of using a fixed-
depth network, this thesis makes a trade-off between feature extraction ability
and parameter scale according to patch size, so that the model can maintain
relatively reasonable representation ability and training stability under
different input scales. If the output of the $l$-th convolution module is
denoted by $A^{(l)}$, the basic operation of each layer can be summarized as
\begin{equation}
    A^{(l)}=\operatorname{Pool}\!\left(\operatorname{ReLU}\!\left(W^{(l)}*A^{(l-1)}+b^{(l)}\right)\right)
    \label{eq:cnn-block-method}
\end{equation}
\par After the final convolution and pooling layer, the feature map is
flattened and fed into a fully connected layer to obtain the class score:
\begin{equation}
    \mathbf{o}=W_f\,\operatorname{vec}\!\left(A^{(L)}\right)+\mathbf{b}_f
    \label{eq:cnn-fc-method}
\end{equation}

\subsubsection{Optimization and Noise Augmentation}
\par Training uses the Adam optimizer and weighted cross-entropy loss
\cite{bottou2012stochastic}. For the training sample set
$\{(\mathbf{x}_i,y_i)\}_{i=1}^{N}$, if the sample number of class $c$ is
$n_c$, the loss weight satisfies
\begin{equation}
    \alpha_c \propto \frac{1}{n_c}
    \label{eq:cnn-class-weight-method}
\end{equation}
\par During optimization, the weights are first computed according to the sample
number of each class and then incorporated into the weighted cross-entropy loss
function. At the same time, whether the resampling strategy is enabled depends
on the specific experimental setting and will be compared separately in the
later experimental section. Therefore, this section only explains that it is
included in the training framework and does not draw conclusions in advance.
In addition, a small Gaussian noise perturbation is added to the input during
data loading. This design is not intended to compensate for insufficient basic
discriminative ability of CNNs, but to further improve their adaptability to
acquisition noise, local brightness variation, and slight imaging
perturbations when the model already has relatively good accuracy. If the
normalized input is $\mathbf{x}$ and the standard deviation of the noise is
$\sigma_n$, the augmented input can be written as
\begin{equation}
    \mathbf{x}'=\operatorname{clip}\!\left(\mathbf{x}+\boldsymbol{\epsilon},\,0,\,1\right),\qquad
    \boldsymbol{\epsilon}\sim\mathcal{N}(0,\sigma_n^2 I)
    \label{eq:cnn-noise-method}
\end{equation}
\par where the default noise standard deviation in this thesis is set as
$\sigma_n=0.03$. This design provides a lightweight and controllable robustness
enhancement for limited-sample scenarios without significantly changing the
focus property itself.

\subsection{Evaluation}
\subsubsection{Evaluation and Prediction Settings}
\par In the evaluation setting, both the training set and validation set are
generated by the same preprocessing, patch division, and automatic labeling
pipeline. In the validation stage, patches with the textureless label $y=-1$
are uniformly removed. Accuracy, classification report, and confusion matrix
\cite{schutze2008introduction} are then calculated for the four models, and the
patch-level predictions are projected back into the original image space to
generate prediction label overlay maps
\cite{Long_2015_CVPR,Zhou_2016_CVPR}. Suppose the validation set contains
$N_v$ valid patches, the model prediction is $\hat{y}_i$, and the true label
is $y_i$. Then the overall accuracy is defined as
\begin{equation}
    \operatorname{Acc}=\frac{1}{N_v}\sum_{i=1}^{N_v}\mathbf{1}(\hat{y}_i=y_i)
    \label{eq:accuracy-method}
\end{equation}
\par In addition to accuracy, classification report, and confusion matrix, this
thesis also projects the patch-level prediction results back into the original
image space to generate prediction label overlay maps, so that the recognition
effect and spatial distribution characteristics of different models on local
focus regions can be observed more intuitively. Specifically, according to the
position index of each patch in the original image grid, the predicted labels
are mapped back to the corresponding regions, restored to the original image
size through nearest-neighbor interpolation, and then overlaid for display.
This process does not participate in metric calculation, but can be used as an
auxiliary basis for judging the consistency of model output and the
reasonableness of boundary positions.

\par It should also be noted that for the binary CNN, the prediction result
depends not only on the softmax probability itself, but also on the decision
threshold of class $1$. In the default setting of this thesis, this threshold
is taken as $0.5$. In actual prediction, the decision can be made according to
the probability threshold $\tau_c$ of class $1$:
\begin{equation}
    \hat{y}=
    \begin{cases}
        1, & \hat{p}_1\ge \tau_c, \\
        0, & \hat{p}_1<\tau_c,
    \end{cases}
    \qquad \tau_c=0.5
    \label{eq:cnn-binary-threshold}
\end{equation}
\par Since this threshold can significantly change the partition result between
the sharp and blur classes in the binary task, it should be regarded in the
subsequent experimental analysis as one of the important prediction parameters
affecting the binary performance of the CNN. In contrast, under the three-
class setting, both the CNN and classical classifiers use the class with the
maximum score as the final prediction output. Through unified evaluation and
projection-based visualization, the discrimination characteristics of
different methods in local focus-state recognition can be compared more
intuitively.

\subsection{Experimental Design}
\subsubsection{Overall Experimental Logic}
\par To ensure fairness and interpretability of the comparison results, this
thesis keeps the preprocessing pipeline unchanged in the experimental design.
That is, all experiments share the same image normalization, patch division,
automatic labeling, and training/validation data organization. On this basis,
the overall experiments are organized into the following three levels:
\begin{itemize}
    \item \textbf{Pre-experiments}: used to determine key parameters of
    classical machine learning models and CNN;
    \item \textbf{Main experiments}: binary and three-class comparison under
    fixed parameter settings, used to analyze the overall performance of
    different models;
    \item \textbf{Supplementary analyses}: further examining the influence of
    factors such as sampling strategy, threshold setting, and computational
    efficiency on the results.
\end{itemize}

\par It should be further clarified that the comparison among different models
in this thesis does not require classical machine learning and deep learning to
be completely identical in model structure, training mechanism, or engineering
implementation details. Instead, this thesis is more concerned with whether
they can reach stable and usable task performance after reasonable design and
tuning within their own paradigms, and then compares their practical
applicability in the patch focus detection scenario. Therefore, natural
implementation differences between machine learning methods and deep learning
methods, such as the use of principal component analysis (PCA) in traditional
models and the easier benefit of convolutional neural networks from hardware
parallel acceleration during training, are not regarded here as variables that
must be strictly controlled to be identical. Rather, they are considered normal
technical means used by each type of method to reach a usable state in
practice. In other words, the focus of comparison in this thesis is not to
pursue strict architectural isomorphism, but to examine the actual performance
that different methods can achieve after reasonable configuration under a
unified task, unified data source, and unified evaluation standard.

\subsubsection{Pre-Experiments for Parameter Selection}
\par The pre-experiment part contains four groups of comparisons, whose goal is
to determine the values of two key parameters, namely PCA dimension and number
of training epochs, under different task settings. Specifically, they include:
\begin{itemize}
    \item comparing the influence of different PCA settings on validation
    performance for classical machine learning models under the binary setting;
    \item comparing the influence of different PCA settings on validation
    performance for classical machine learning models under the three-class
    setting;
    \item comparing the influence of different training epochs on convergence
    and final validation performance for CNN under the binary setting;
    \item comparing the influence of different training epochs on convergence
    and final validation performance for CNN under the three-class setting.
\end{itemize}
\par Since these four groups of experiments mainly serve parameter selection,
their role is to provide unified and reasonable settings for the subsequent
main experiments rather than to serve directly as the final basis for judging
which model is better.

\subsubsection{Main Experiments}
\par After completing the pre-experiments, this thesis further conducts the
main experiments. In this stage, classical machine learning models and the
lightweight CNN are independently trained and evaluated under the binary and
three-class tasks, and their differences in discrimination performance are
compared under unified evaluation metrics. The main experiments have two core
objectives:
\begin{itemize}
    \item comparing the performance and evaluation results of different models
    under the two task settings of binary and three-class classification;
    \item comparing the performance trends of these models under different
    training sample conditions, so as to analyze their sensitivity to sample
    size and their applicability in low-sample scenarios.
\end{itemize}

\subsubsection{Sample-Size Analysis}
\par Based on this objective, the main experiments do not focus only on the
final result under a single training ratio. Instead, both task setting and
sample size are incorporated into the analysis as comparison dimensions. With
this design, the thesis can not only observe the relative performance of
classical machine learning methods and lightweight CNNs in binary and three-
class tasks, but also further reveal their stability, advantages, and
limitations under training sample conditions from $20\%$ to $100\%$.

\subsubsection{Supplementary Analyses}
\par In addition, this thesis sets two supplementary analyses:
\begin{itemize}
    \item for the resampling strategy in CNN training, comparing the influence
    of enabling and disabling it, so as to analyze the difference between
    resampling and weighted loss in handling class imbalance;
    \item for the evaluation stage of the binary CNN, examining the influence
    of the prediction threshold setting for class $1$ on precision, recall,
    and F1-score, so as to analyze the role of threshold calibration in output
    decision.
\end{itemize}
\par Both supplementary analyses serve the further interpretation of the main
experimental results and do not change the unified training configuration used
in the main text.
